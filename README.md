# CLI Sliding Puzzle

A command-line Sliding Puzzle game written in F#.

Rearrange randomly shuffled numbered tiles into ascending order by moving tiles adjacent to the empty space.

---

## Project Requirement

1. The user is prompted to select the puzzle size
    a. The user enters 1 for a 3x3 puzzle or 2 for a 4x4 puzzle.
    b. If the input is invalid, the program displays an error message and prompts the user again.

2. After a valid selection, the program displays a tile grid with randomly arranged numbered tiles and one empty space.
    a. The 3x3 puzzle contains tiles numbered from 1 to 8.
    b. The 4x4 puzzle contains tiles numbered from 1 to 15.
3. The program records the start time when the game begins (but not displayed explicitly)
4. The user makes a move by entering the number of a tile adjacent (up, down, left, or right) to an empty space.
    a. If the selected tile is not adjacent to the empty space, the program displays an empty message and prompts the user again.
5. When a valid move is made, the selected tile swaps positions with the empty space, and the move count increases by 1.
6. After each valid move, the program displays the updated tile grid and the current move count.
7. The game ends when all tiles are arranged in ascending order from left to right and top to bottom.
8. When the game ends, the program displays the total number of moves and the elapsed time.
9. The initial puzzle configuration is generated by applying a sequence of valid random moves to the solved state, ensuring that the puzzle is solvable.

## How to Play

### Puzzle Selection

At the start of the game, choose a puzzle size: 

- 1 for a 3x3 puzzle
- 2 for a 4x4 puzzle

### Objective 

Arrange all numbered tiles in ascending order from left to right and top to bottom.

### Making a Move

1. The puzzle board is displayed.
2. Enter the number of a tile adjacent to the empty space.
3. If the move is valid, the selected tile swaps positions with the empty space.
4. Invalid inputs or invalid moves display an error message and re-prompt the user.
5. Enter q to quit the game.

### Winning

The game ends when all tiles are arranged in ascending order.
The total move count and elapsed time are displayed after completion.

## Additional Information

### Requirement Changes

No requirement changes were made after the proposal submission.

### LLM Usage

LLM was used for assistance with some F# built-in functions, such as random number generation and time-related functions.

Some prompts required minor clarification or modification, such as adapting variable names and generator code to fit this specific project structure. Since the usage was mainly for referencing function usage and syntax, extensive clarification was rarely necessary, though manual modification was still needed to integrate the code into the project.

One limitation was that generated code sometimes did not exactly match the intended project organization because the prompts were given in a more generic form, so manual adjustments were needed.

## Rules Summary

- Only tiles adjacent to the empty space can be moved.
- Invalid inputs or invalid moves are not allowed.
- The puzzle is randomly shuffled into a solvable board at the start of the game.
- The game ends when all tiles are arranged in ascending order.
- The total move count and elapsed time are displayed when completed.

Tested with .NET 10 on macOS.
